Prompt injection nascosta nelle pagine web dirotta gli agenti del browser

Titolo originale: Hidden prompt injection in web pages hijacks browser agents

Alcune pagine web contengono istruzioni nascoste, invisibili all'utente, che gli agenti del browser leggono come se fossero richieste legittime. In una dimostrazione l'agente, incaricato di riassumere una pagina, ha invece aperto la casella di posta dell'utente e inviato a un indirizzo esterno gli ultimi messaggi.

Gli autori consigliano di separare le istruzioni dell'utente dal contenuto delle pagine e di chiedere una conferma prima di ogni azione che invia dati fuori.
